# 🔧 MES Hidden Coding Calculator

**Porsche MES 隐藏功能代码计算器** — 支持多选合并、Bit 位可视化、手动调整

🔗 **在线使用：** https://stormeye818.github.io/mes-coding-byte-calculator/

---

## ✨ 功能特性

- 📋 **多选合并**：同时勾选多项隐藏功能，共享 Byte 自动合并为一次输入、一次计算
- 🔢 **Bit 可视化**：原值和改后值的 8 个 Bit 位上下对比，变化项蓝色高亮
- ✋ **手动调 Bit**：点击任意 Bit 位翻转，支持特殊情况手动调整
- 📱 **全平台适配**：电脑、平板、手机浏览器均可直接使用
- 🔗 **零依赖**：纯 HTML 单文件，无需安装，打开即用

## 📖 使用教程

### 1️⃣ 选择隐藏功能

在顶部勾选你需要开启的隐藏功能，可多选。带有下拉菜单的功能（如 DDA、LKA）需先选择具体模式。

> 💡 多个功能涉及同一个 Byte 时会自动合并，避免重复输入。

### 2️⃣ 查看修改说明

每个 Byte 卡片上方会列出需要修改的 Bit 位和目标值：
- 🟢 绿色数字 = 目标值为 1
- 🔴 红色数字 = 目标值为 0
- 灰色括号内 = 来源功能

### 3️⃣ 输入原值

在「请输入Byte原值」输入框中填入当前 Byte 的 16 进制值（两位，如 `04`、`7F`）。

### 4️⃣ 查看结果

输入原值后自动计算并显示：
- **上排 Bit**：原值的 8 个 bit 位（变化项蓝色高亮）
- **下排 Bit**：改后值的 8 个 bit 位（可点击翻转）
- **结果区**：`原值 HEX → 改后 HEX` + 二进制对比

### 5️⃣ 手动调整（可选）

如果需要手动微改某个 Bit，直接点击「改后 Bit」行的对应格子即可翻转。手动修改后会出现「↩ 恢复自动计算值」按钮。

### 6️⃣ 复制结果

点击底部「📋 复制所有修改」一键复制全部 Byte 的修改结果。
